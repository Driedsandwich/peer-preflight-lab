# Peer Preflight prototype

Serve the repository root over HTTPS (or loopback HTTP) and open `/app/`. The
page uses native ES modules and Web Crypto. For local samples, follow the
[two-origin guide](../serve_two_origins.md) and serve `.` instead of
`lab-caller` on port 8081. Open `http://127.0.0.1:8081/app/`.

After a check, `window.peerPreflight.lastResult` holds this JSON-compatible data.

| Field | Value |
| --- | --- |
| `peer` | `{ url, name, agentCount }`. The count can be `null`. |
| `verdict` | `"Pass"`, `"Caution"` or `"Block"`. |
| `findings` | In severity order, each with `{ id, severity, title, detail, evidence }`. |
| `changes` | The core diff with fingerprint, instructions, tools and destinations, or `null` when there is no comparison. |
| `fingerprint` | The full SHA-256 hash, or `null` if the public files could not be read. |

The value starts at `null`. The version 1 lock and full snapshots are saved
together in browser storage. Export downloads the portable version 1 lock
with the fingerprints. Saving a decision requires a fingerprint.

The tours demo uses the pin generated by `scripts/set_origins.mjs` from
`lab-peers/tours/_history/v1/tours.hocon`. The site embed and HTTP API are
planned for the next version.
