          Words used here
            Peer
            Another site's agent network.
            Pin
            Save a version in your browser to compare on the next check.
            Fingerprint
            A hash identifying the published files. The comparison shows its first seven characters.
            Origin
            A URL's scheme, hostname and port taken together.
            Outbound origin
            An origin the peer declares as a destination.
            CORS
            The browser's rules for reading files from a different origin.
            Router
            The service that receives requests for an AI model.
            Agent count
            The number of agents defined in the published network.
