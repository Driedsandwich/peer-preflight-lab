Peer Preflight

Check another site's agent network before your site lets it run in your visitors' browsers.

Preflight API

Check a peer

Start here: press a sample peer below to check it, or paste a peer network URL and press Check.

After a check: Pass lets you pin this exact version. Caution and Block ask you to read the reasons first. Pin and Block stay in this browser.

    This demo starts from a pin of an older version of this sample peer, saved in advance. It replaces any saved tours entry.

    Check only reads the peer's public files (its manifest, network and links) without cookies or credentials. Nothing about you or your site is sent, no AI model runs, and nothing costs money.

    For cross-origin reads, the browser sends this page's origin for CORS. Pin and Block are recorded only in this browser and are never sent anywhere.

          Words used here
            Peer
            Another site's agent network.
            Pin
            Save a version in your browser to compare on the next check.
            Fingerprint
            A hash identifying the published files. The comparison shows its first seven characters.
            Origin
            A URL's scheme, hostname and port taken together.
            Outbound origin
            An origin the peer declares as a destination.
            CORS
            The browser's rules for reading files from a different origin.
            Router
            The service that receives requests for an AI model.
            Agent count
            The number of agents defined in the published network.
